# Oral coaching (Mundtlig kommunikation)

The oral grade counts **double**. This is typed practice (or voice, if the learner dictates and pastes the transcript) — judge it as spoken
language: fluency, coherence, reasoning, complexity; spelling doesn't count.

Material: `pd3.py pick O2`, then `get <sitting> oral` (task sheet) and `get <sitting> oral_key` (examiner booklet with the actual questions and the mandatory questions per topic).
Use the examiner's real questions from `oral_key` — that's the most realistic practice available.

## Delprøve 1 — prepared presentation (~2 min + ~2½ min questions)
Help them build it (Sokolova's method):
1. Say the plan: *Mit emne er … Jeg vil først fortælle, hvad … er. Derefter vil jeg fokusere på fordele og ulemper ved …*
2. Definition / reasons for the phenomenon.
3. **Assessment is the longest part** (advantages/disadvantages, solutions, effects).
4. Leave "teasers" — statements that invite the 4 question types (e.g. mention conditions without listing them → invites *opklarende*).
5. Write it out, learn it by heart, bring 10–15 keywords only. ~250–280 words ≈ 2 minutes spoken.
Then rehearse: they "present" (type/paste), you time by word count, then ask 4 follow-ups — one of each type (opklarende, uddybende, begrundelse, stillingtagen).

## Delprøve 2 — unprepared topic (~4½ min)
Run it like the exam: present the topic in one line, then ask the examiner booklet's questions **one at a time**, in order, then 1–2 follow-ups that push for *hvorfor* and *stillingtagen*.
Don't describe the picture — it's inspiration only.

Answer frame to train (Sokolova):
> *Der kan være mange årsager til det.* → *En årsag er, at …* → explain with *fordi / for / nemlig* → example (*Fx kender jeg …*) → mini-conclusion (*Så derfor tror jeg, at …*).
For pros/cons questions: *På den ene side … På den anden side … Hvis jeg skal tage stilling, mener jeg, at …*

## Feedback (per answer, short — it's a conversation)
```markdown
✅ Clear and reasoned. / 🟡 Understandable but thin.
**Structure:** reason ✅ · example ❌ · mini-conclusion ✅
**Upgrade:** "Det er godt, fordi det er godt for miljøet." → **"Det er en fordel, fordi det mindsker CO₂-udledningen, og på længere sigt kan det …"**
**Language (only errors that recur or blur meaning):** 🔴 "I dag mange unge bruger …" → "I dag **bruger** mange unge …" (inversion) — skip trivia.
```
At the end, a holistic grade (12/10/7/4/02) with one sentence why, log `pd3.py log O2 <sitting> <grade> 12`, and record recurring patterns with `mistake add`.

Weights to remember: an excellent Delprøve 1 cannot compensate a weak Delprøve 2. Spend ~2/3 of oral practice on Delprøve 2.
